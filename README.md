# Insertion Sort Visualizer

An interactive web-based visualizer that demonstrates the **Insertion Sort algorithm step by step**. The project allows users to observe comparisons, element shifts, insertions, and the construction of the sorted portion of the array.

## 🌐 Live Demo

[Open the Insertion Sort Visualizer](https://apurva4-bot.github.io/visualizer-/)

## ✨ Features

* Enter a custom array of integers
* Generate a random array
* Reset the visualization
* Move to the first, previous, next, or last step
* Play the sorting process automatically
* Pause the automatic visualization
* Adjust the visualization speed
* View the sorted and unsorted portions of the array
* Highlight the current and comparing elements
* Display comparison and movement statistics
* Track sorting progress step by step

## 🧠 How Insertion Sort Works

Insertion Sort builds the sorted array one element at a time.

For each element:

1. Select the current element.
2. Compare it with elements in the sorted portion.
3. Shift larger elements one position to the right.
4. Insert the current element into its correct position.
5. Repeat until the entire array is sorted.

The visualizer displays these operations interactively so that the sorting process can be understood more easily.

## 📊 Complexity

| Case         | Time Complexity |
| ------------ | --------------- |
| Best Case    | O(n)            |
| Average Case | O(n²)           |
| Worst Case   | O(n²)           |

**Space Complexity:** O(1)
